System Modules

  The Cyber Attack Prediction System consists of the following modules, designed to provide secure access, real-time attack detection, dataset analysis, and effective threat monitoring.

  1. Login and Registration Page
     
  The Login and Registration Page provides secure user authentication and access control. New users can create an account, while registered users can log in using their credentials. Only authenticated users can access the system's main features, helping protect the application from unauthorized access.

  3. Home Page
     
  The Home Page serves as the main interface of the application. It provides an overview of the Cyber Attack Prediction System and allows users to navigate easily between different modules, including Detection, Dataset Upload, and Dashboard. Its user-friendly layout ensures smooth navigation and easy access to system functionalities.

  4. Detection Page
     
  The Detection Page enables users to perform real-time cyberattack detection by entering network traffic or system behavior data. The submitted input is processed by the backend machine learning model, which predicts the traffic category and generates the following results:

    o Predicted Attack Type: Identifies normal traffic or the detected attack category.
    
    o Confidence Score: Displays the model's confidence in its prediction.
    
    o Risk Level: Indicates the severity of the detected threat.
    
    o Recommended Security Actions: Provides appropriate security suggestions based on the prediction.
  
  This module helps users identify potential cyber threats and understand the associated security risks.
  
  5. Upload Dataset Page
     
  The Upload Dataset Page allows users to upload network traffic datasets in CSV or JSON format for batch analysis. The backend processes the uploaded data using the trained machine learning model and generates classification results.
  
  The module provides:
  
     o Total number of network traffic records analyzed.
     
     o Number of detected attacks.
     
     o Classification of normal and malicious traffic.
     
     o Attack distribution and confidence statistics.
     
     o Export options to download analysis results in CSV or PDF format.
     
     o This functionality helps users analyze large volumes of network traffic efficiently.
  
  5. Dashboard Page
     
  The Dashboard Page provides a centralized view of network security activities and attack statistics. It displays detection results, attack logs, and system performance information through interactive charts, graphs, and data tables.
  
  Key dashboard features include:
  
     o Total network traffic records analyzed.
     
     o Total detected attacks and normal traffic.
     
     o Distribution of different attack categories.
     
     o Attack frequency and detection statistics.
     
     o Risk-level monitoring using color-coded indicators.
     
     o Recent attack logs and classification results.
  
  The dashboard helps users monitor network activities, understand attack patterns, and analyze potential security threats effectively.
